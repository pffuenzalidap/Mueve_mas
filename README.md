Mueve Más 🏃‍♂️👵

Mueve Más es una plataforma clínica digital (Single Page Application) orientada a la kinesiología, autogestión y bienestar integral del adulto mayor.

Diseñada con un enfoque gerontológico, la aplicación facilita la evaluación remota de movilidad, la entrega de pautas de ejercicio activo (basadas en el peso corporal y prevención de caídas), y la gestión de visitas kinesiológicas a domicilio o por tele-rehabilitación.

✨ Características Principales (Versión Premium)

Triage Clínico Interactivo (Modal):

Cuestionario digital fluido que evalúa el objetivo del paciente y la seguridad en el hogar.

Generación de recomendaciones automáticas adaptadas al nivel de independencia (Tele-Rehab PRO vs. Visita a Domicilio).

Agendamiento Inteligente y Concurrencia:

Sistema de calendario interactivo en ventana modal para reservar visitas a domicilio.

Implementación de un temporizador de bloqueo de 10 minutos (conteo regresivo visual) para asegurar la hora mientras se procesa el pago.

Pasarela de Pago Simulada:

Flujo de Checkout completo con simulación de conexión bancaria segura (tipo Webpay).

Animación de procesamiento y redirección automática tras pago exitoso.

Diseño Accesible y de Alto Impacto (UI/UX):

Navegación SPA instantánea sin recargas de página.

Hero section con animación Ken Burns para un aspecto moderno y profesional.

Paleta de colores de alto contraste (tonos Sand, Mint y Primary) y tipografías grandes (Plus Jakarta Sans), optimizadas para la tercera edad y sus cuidadores.

Carrusel interactivo de testimonios de pacientes.

🛠️ Stack Tecnológico

Frontend: HTML5 Semántico, Vanilla JavaScript (ES6+).

Estilos: Tailwind CSS v3 (vía CDN) con configuración de tema personalizado.

Iconografía: Lucide Icons.

Arquitectura: Single Page Application (SPA) unificada, diseñada para ser ligera, rápida y de fácil despliegue.

🚀 Guía de Instalación Rápida

Clona el repositorio:

git clone https://github.com/TU_USUARIO/TU_REPOSITORIO.git
cd TU_REPOSITORIO


Ejecución Local:

No requiere instalación de dependencias (Node.js/NPM).

Simplemente abre el archivo mueve_mas_premium.html (o index.html) en tu navegador, o utiliza la extensión Live Server en VS Code para recarga automática.

Estructura del Código:

La aplicación está diseñada en un formato unificado para facilitar el prototipado rápido, pero su código fuente (CSS interno y JS) está debidamente comentado para separarse en style.css y app.js según se requiera en futuras fases.

👥 Estado del Proyecto

Este proyecto es un prototipo funcional premium enfocado en validar la experiencia de usuario (UX), el flujo de captación (Triage) y la conversión comercial (Checkout) antes de su integración definitiva con un Backend as a Service (BaaS) como Supabase.
